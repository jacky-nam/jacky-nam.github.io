# Project agent memory

Committed home for project-intrinsic knowledge that should travel with the
code. Keep entries here only if they matter to almost every future session;
point to the authoritative file or command instead of repeating it.

## Reference deck

`ReferenceDeck.pdf` at the repo root is generated output — never edit the PDF
directly. The source is plain HTML/CSS under `deck/`. After any deck source
edit, re-render with:

```sh
./deck/render.sh
```

See `deck/README.md` for requirements and details.
